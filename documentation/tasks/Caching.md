# Task: local mail cache behind `olive-mail`

`olive-mail` is still a Himalaya wrapper. Today every `envelope list` / `message read` hits IMAP. Put an incremental Maildir under the wrapper so those same commands are local. Sync is a timer (and a CLI subcommand), not a model.

Status: todo  
Date: 2026-09-01  
Depends on: live IMAP already working via `olive-mail auth` + `olive-mail envelope list`

This is a product feature of this CLI, not a one-off on the Grok Bot VM. The first dogfood mailbox is `hi@nohype.ai` (IONOS) on that VM — see the company `BOT/Email Setup.md` — but nothing in this repo is mailbox-specific. The repo is already decoupled from any real account.

## Goal

- Incremental on-disk copy of Inbox + Sent + Drafts for whatever account `auth` configured.
- Agents keep calling `olive-mail`. Never `himalaya`, `mbsync`, or `notmuch`.
- Himalaya reads the Maildir (offline). IMAP is only for sync.
- Fetch/index costs zero tokens.
- Same secret files as today: `~/.config/olive-mail/<email>.pass`.

## Current

```
olive-mail …  →  himalaya -c ~/.config/olive-mail/config.toml …
                  imap.server + passwd.command = cat <email>.pass
```

Fine for a peek. Slow, live, and not a corpus. `auth` writes a single IMAP account and overwrites `config.toml` (open TODO). Send is already gated in `olive-mail` (no SMTP; `message send` / `smtp` / `--send` rejected).

## Target

```
IMAP (host from config.toml)
    │  olive-mail sync   =  mbsync (UID, new/changed only)
    ▼
$XDG_DATA_HOME/olive-mail/<email>/     Maildir (not git)
    │
    └─ himalaya  maildir.root = that path
           ▲
olive-mail mailbox|envelope|message …  (unchanged argv)
```

Timer every 10 min: `olive-mail sync`. The wrapper may also sync on a read if `.last-sync` is older than 20 min — the agent does not decide. `flock` so timer and on-demand do not overlap.

## Non-goals

- Changing the agent-facing command (`olive-mail`, Himalaya argv)
- MCP / plugins / public URL
- Markdown dump of the mailbox
- Enabling send (`MAIL_SEND` stays off; humans send from the real client)
- Granular permissions (separate TODO; cache does not replace that)
- Privilege split (Maildir is as readable as today’s `.pass` file to the same Unix user)
- Hardcoding `hi@`, IONOS, or `~/mail/hi/`
- A SKILL.md or a parallel `~/mail-cache/` tree — the CLI is the interface
- Replacing Himalaya; exposing Neverest/pimdir (mbsync is the v1 sync)

## Layout (machine, not git)

Reuse the existing config dir. Data goes in XDG, not `~/.config/himalaya/` and not `~/mail/`.

```
~/.config/olive-mail/config.toml       # Himalaya: keep imap.* for sync; add maildir.root
~/.config/olive-mail/<email>.pass      # unchanged, mode 0600
~/.config/olive-mail/mbsyncrc          # generated by olive-mail, not hand-written
$XDG_DATA_HOME/olive-mail/<email>/     # Maildir: Inbox, Sent, Drafts
  .last-sync
  sync.log
```

`$XDG_DATA_HOME` is `~/.local/share` when unset. Credentials stay out of git (`.gitignore` already covers `*.pass` and `config.toml`). Do not commit Maildir.

Folders: discover once with `olive-mail mailbox list`. IMAP default is `INBOX`; some hosts (IONOS) use `Inbox`. Sent may be `Sent` / `Sent Items`; Drafts may be `Drafts` / `Entwürfe`. Map names in the generated `mbsyncrc` and in `mailbox.alias.*`. Do not bake host-specific names into the script.

## Done when

- Second `olive-mail sync` is incremental (seconds).
- `olive-mail envelope search` / `message read` work with IMAP unreachable.
- A bot answers a mail question via `olive-mail` with no live IMAP on the read path.
- Timer has run unattended ≥ 1 hour.
- Sync path never invokes a model.
- Nothing in the repo names a real mailbox.

## Risks

| Risk | Mitigation |
|---|---|
| Host folder names (`Inbox` vs `INBOX`, `Sent Items`, `Entwürfe`) | `olive-mail mailbox list` once; map in generated `mbsyncrc` + `mailbox.alias.*` |
| Himalaya ids ≠ notmuch ids | Do not expose notmuch; one id space (Himalaya) unless search is wrapped |
| Two-way sync deleting server mail | `Expunge None`; pull-only except Drafts |
| `auth` overwrites `config.toml` | Preserve cache keys, or restore them on the next `sync` |
| Timer vs on-read `sync` overlap | `flock` inside `olive-mail sync` |
| Box grows forever | Later: `MaxAge` / archive; not v1 |
| Agent `rg`s the Maildir and skips the CLI | Same Unix-user threat as today’s `.pass` file; permissions TODO is separate |
| Homebrew Himalaya without maildir | Verify `maildir.root` works on the brew build before flipping the default |

## Out of scope until this works

Markdown-per-message export, attachments sidecar, MCP wrapper, enabling send, per-agent folder/sender/date filters.
